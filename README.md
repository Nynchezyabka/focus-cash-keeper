# 🌿 Бережный бюджет

**Спокойные личные финансы для людей с СДВГ**

## Зачем это нужно

Большинство бюджетных приложений бросают через неделю: пропустил три дня, накопилась куча чеков, стыдно заходить, всё сломалось. «Бережный бюджет» сделан так, чтобы такого не случалось:

- **Одна главная цифра.** Не пугающий остаток на месяц, а «сегодня свободно: N ₽».
- **Ничего не нужно вспоминать.** Забыли записать траты? Просто впишите, сколько сейчас на карте, и расчёт подстроится под реальность.
- **Никаких нотаций.** Перерасход не краснеет и не ругается: приложение спокойно предлагает, что с ним сделать.
- **Ваши данные у вас.** Бюджет хранится на вашем телефоне. Аккаунт не нужен.

## Как считается «Сегодня свободно»

```
Сегодня свободно = (деньги на карте и наличные − отложенное на платежи) ÷ дни до дохода
```

Например: на карте и в наличных 30 000 ₽, до зарплаты 12 дней, в этот период нужно оплатить 6 000 ₽ обязательных платежей. Тогда (30 000 − 6 000) ÷ 12 = **2 000 ₽ в день**. Платежи уже «забронированы» и не потратятся случайно. Расчёт обновляется сам, когда вы вносите траты, доходы или сверяете остаток.

## Что умеет

| | |
|---|---|
| 🎯 **Сегодня свободно** | Большая цифра на главном экране. Пересчитывается сама. |
| 💳 **Карта, наличные, накопления** | Нажмите на сумму и впишите, сколько есть на самом деле. Вспоминать каждую чашку кофе не нужно. |
| 💰 **План доходов** | Аванс и зарплата на карту или наличными. «Пришли», «Перенести» или «Не учитывать в этом месяце». |
| 🧾 **План платежей** | Регулярные и разовые платежи, долги. Деньги откладываются заранее, дальние платежи (налоги в декабре) копятся понемногу. Можно вносить частями. |
| 🌤 **Перерасход без стыда** | Спокойный выбор: распределить на оставшиеся дни, взять из подушки или занять с датой возврата. |
| ⚡ **Быстрый ввод** | Сумма, потом категория в одно касание. Или списком «такси 450, кофе 380», голосом либо скриншотом из банка. |
| 🗂 **Три кучки** | Обязательное, Безопасность, Жизнь и радости. Можно создавать свои категории и иконки. |
| 📊 **Аналитика** | Расходы и доходы по группам или по категориям. |
| 🤝 **Помощник** | Можно обсудить траты, оценить покупку, разобрать скриншот. Опирается только на ваши цифры и не ругает за кофе. |
| 👨‍👩‍👧 **Семья** | Каждый ведёт свой бюджет, а отдельный экран показывает общую картину. |
| ↩️ **Отмена** | Любое действие можно отменить в течение нескольких секунд. |

## Установить на телефон

Приложение работает прямо в браузере, магазин приложений не нужен.

- **Android (Chrome):** откройте ссылку → ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран Домой».

После установки приложение открывается без интернета и обновляется само. Что нового, показывает окно «Что нового» после обновления.

## Где хранятся данные

| Что | Где |
|---|---|
| Ваш бюджет (траты, планы, категории) | **Только на вашем телефоне**, в памяти браузера. Аккаунт не нужен. |
| Резервная копия | Настройки → Экспорт и Импорт (файл JSON). Ключ ИИ в копию не попадает. |
| Ключ ИИ (необязательно) | Только в вашем браузере, уходит напрямую в сервис ИИ. |
| Данные семьи | В облаке, только если вы сами включили семейный доступ (см. ниже). |

**Ключ ИИ необязателен.** Подходят ключи OpenAI, OpenRouter, Google Gemini, Groq, Anthropic, DeepSeek и xAI. Без ключа работает встроенный разбор: он бесплатный, работает без интернета и узнаёт знакомые слова вроде «такси», «аптека», «кофе». Если ИИ нужен только для сложных фраз, в настройках есть «экономный режим»: ИИ зовётся, только когда встречается незнакомое слово.

## Семейный доступ

У каждого человека **свой бюджет, свои категории и свои траты**. Общего котла нет. Семья нужна, чтобы на отдельном экране увидеть общую картину двух бюджетов.

**Как подключиться**

1. Первый человек: Настройки → «Семейный доступ» → «Создать семью». Подписаться («Как вас назвать?») и показать второму код или QR.
2. Второй: Настройки → «Семейный доступ» → «Присоединиться». Навести камеру на QR или ввести код.
3. В нижнем меню появится вкладка «Семья».

**Что видно на экране «Семья»**

- **Сегодня свободно вместе:** сумма «сегодня свободно» обоих.
- **До ближайшего дохода:** сумма дневных норм обоих × число дней до *ближайшей* из двух зарплат. Например, у одного 500 ₽/день и 10 дней до дохода, у другого 1 000 ₽/день и 7 дней: сегодня 1 500 ₽, до ближайшего дохода (500 + 1 000) × 7 = 10 500 ₽.
- Деньги на картах и в наличных, обязательные платежи впереди, накопления.
- Без сравнений «кто потратил больше» и без красного цвета.

Все семейные цифры считаются по формуле из свежих данных обоих и нигде не хранятся готовыми числами.

**Что видит партнёр.** В настройках каждый выбирает: «только итоги» (по умолчанию) или «итоги и траты». Траты партнёр может только смотреть.

**Переводы внутри семьи.** При записи траты или дохода есть переключатель «Перевод внутри семьи». Деньги на карте меняются как обычно, но в семейные итоги такая запись не попадает.

**Что уходит в облако:** имя, которое вы указали, итоговые цифры (дневная норма, дата следующего дохода, остаток, отложенное на платежи, накопления, суммы за месяц), а список трат только если вы сами выбрали «итоги и траты».
**Что не уходит никогда:** ключ ИИ, переписка с Помощником, раздел «О себе», категории и планы.

**Безопасность.** Код семьи длинный и случайный (16 символов), в базе хранится только его хэш. Читать и писать можно только через проверку кода и личного ключа участника. Каждый записывает только в свою строку. «Новый код» сразу отключает старый, «Выйти» удаляет ваши данные из облака, «Удалить» удаляет семью целиком.

**Без интернета** всё работает как обычно. Изменения отправятся сами, когда появится связь.

## Как выложить своё приложение

Приложение работает на любом хостинге, **даже статическом** (Layero, Tuqo, GitHub Pages). Свой сервер не нужен: для семьи телефон обращается к базе напрямую, через защищённые функции внутри базы. Они проверяют код семьи и личный ключ участника, а сами таблицы закрыты для прямого чтения.

**1. Код.** Подключите репозиторий к хостингу (деплой из ветки `main`). Сборка: `npm run build`.

**2. База для семьи.** Создайте проект на [supabase.com](https://supabase.com). Бесплатного тарифа хватает, данных у семьи совсем мало.

1. Создайте проект в регионе Европа.
2. Откройте SQL Editor, вставьте **всё содержимое файла `supabase/family-setup.sql`** и нажмите Run. Делать это нужно один раз.
3. В Project Settings → API скопируйте **Project URL** и **публикуемый ключ** (Publishable key или `anon`). Секретный ключ не нужен.

**3. Переменные окружения на хостинге.** На Layero: проект → «Настройки» → «Переменные окружения» → «Добавить».

| Имя | Что вписать |
|---|---|
| `VITE_SUPABASE_URL` | Project URL (`https://….supabase.co`) |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | Публикуемый ключ (`sb_publishable_…` или `anon`) |

Эти значения публичные: они и так видны в коде сайта, а защиту дают функции в базе. Значения подставляются **при сборке**, поэтому после добавления переменных запустите новую сборку (Redeploy).

**4. Проверка.** Откройте сайт → «Семья» → «Проверить связь с облаком». Кнопка проверяет всю цепочку и говорит, что не так:

| Ответ | Что делать |
|---|---|
| «Не настроены адрес и ключ базы» | Добавьте переменные из шага 3 и пересоберите сайт |
| «Ключ не подходит» | Проверьте, что вписан публикуемый ключ того же проекта |
| «База не подготовлена для семьи» | Выполните `supabase/family-setup.sql` (шаг 2) |
| «База не отвечает» | Сервис недоступен из этой сети. Попробуйте другой интернет |
| «Нет интернета» | Ждать связи. Приложение работает и без неё |
| «Всё работает» | Готово |

Если облако не настроено или недоступно, приложение остаётся полностью рабочим как автономное, а экран «Семья» спокойно объясняет, что делать.

## Для разработчиков

**Стек:** React 19 · TanStack Start · Vite · TypeScript · Tailwind CSS v4 · shadcn/ui · Lucide · Supabase (только для семьи). Сделано на [Lovable](https://lovable.dev).

```sh
npm i
npm run dev      # запуск для разработки
npm test         # тесты (vitest)
npm run build    # сборка
```

**Где что лежит**

| Путь | Что там |
|---|---|
| `src/lib/budget.ts` | Состояние, расчёты («Сегодня свободно», резерв, доходы, платежи, накопления) |
| `src/lib/family.ts` | Снимок для семьи, формула `familyTotals`, очередь синхронизации |
| `src/lib/family-api.ts` | Вызовы защищённых функций базы для семьи и проверка связи |
| `src/lib/fx.ts` | Валюты и курсы ЦБ РФ |
| `src/lib/parse.ts` | Разбор трат: встроенный и через ИИ |
| `src/lib/pwa.ts`, `public/sw.js` | Установка на телефон, офлайн и обновления |
| `src/lib/whatsnew.ts` | История версий для окна «Что нового» |
| `src/routes/` | Экраны: главная, платежи, доходы, аналитика, помощник, семья, настройки |
| `supabase/family-setup.sql` | Всё, что нужно базе для семьи (одним файлом) |

**Принципы проекта** (подробнее в [`AGENTS.md`](AGENTS.md))

- Local-first: бюджет живёт в `localStorage`, бэкенд и вход не нужны. Облако только для семейных снимков и необязательно.
- Без регистрации и без красных предупреждений: мягкий, спокойный интерфейс.
- Каждое изменение для пользователя: поднять `APP_VERSION` в `src/lib/pwa.ts` и добавить запись в `src/lib/whatsnew.ts`.
- Планы и идеи: [`roadmap.md`](roadmap.md).
