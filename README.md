# Бережный бюджет

**Спокойные личные финансы для людей с СДВГ.** Приложение отвечает на один вопрос: *«Сколько я могу потратить сегодня со спокойной душой?»* Без регистрации, без таблиц и без чувства вины.

**Открыть:** https://focus-cash-keeper.lovable.app

---

## Что умеет

| | |
|---|---|
| **Сегодня свободно** | Большая цифра на главном: (деньги − отложенное на платежи) ÷ дни до дохода. Пересчитывается сама. |
| **Карта, наличные, накопления** | Нажмите на сумму и впишите, сколько есть на самом деле. Вспоминать каждую чашку кофе не нужно. |
| **План доходов** | Аванс, зарплата, выплаты на карту или наличными. «Пришли», «Перенести» или «Не учитывать в этом месяце». |
| **План платежей** | Регулярные и разовые платежи, долги. Деньги на них откладываются заранее, а дальние платежи (налоги в декабре) копятся понемногу. Можно вносить частями. |
| **Перерасход без стыда** | Спокойный выбор: распределить на оставшиеся дни, взять из подушки или занять с датой возврата. |
| **Быстрый ввод** | Сумма, потом категория в одно касание. Или списком «такси 450, кофе 380», голосом либо скриншотом из банка. |
| **Три кучки** | Обязательное, Безопасность, Жизнь и радости. Свои категории и иконки. |
| **Аналитика** | Расходы и доходы, по группам или по категориям. |
| **Помощник** | Обсудить траты, оценить покупку, разобрать скриншот. Опирается только на ваши цифры и не ругает за кофе и такси. |
| **Семья** | Каждый ведёт свой бюджет, а на отдельном экране видна общая картина двух бюджетов. |
| **Отмена** | Любое действие можно отменить в течение нескольких секунд. |

## Установить на телефон

- **Android (Chrome):** откройте ссылку → ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран Домой».

После установки приложение работает без интернета и обновляется само. Что изменилось, показывает окно «Что нового».

## Где хранятся данные

- **Ваш бюджет хранится только на вашем телефоне**, в памяти браузера. Аккаунт не нужен.
- **Резервная копия:** Настройки → Экспорт и Импорт (файл JSON). Ключ ИИ в копию не попадает.
- **Ключ ИИ (необязательно):** вставьте любой ключ OpenAI, OpenRouter, Gemini, Groq, Anthropic, DeepSeek или xAI. Он хранится только в этом браузере и отправляется напрямую в сервис ИИ. Без ключа работает встроенный разбор: он бесплатный и работает без интернета.

## Семейный доступ

1. Настройки → «Семейный доступ» → «Создать семью». Напишите, как вас называть, и покажите код или QR второму человеку.
2. На втором телефоне: наведите камеру на QR или введите код вручную.
3. Появится вкладка «Семья». На ней видно, сколько свободно сегодня вместе, сколько до ближайшего дохода, остатки, платежи и накопления.

**Что уходит в облако:** имя, которое вы написали, итоговые цифры (дневная норма, дата следующего дохода, остаток, отложенное на платежи, накопления, суммы за месяц). Список трат уходит, только если вы сами выбрали «Итоги и траты».
**Что никогда не уходит:** ключ ИИ, переписка с Помощником, раздел «О себе», категории и планы.
**Где:** в Lovable Cloud. Код семьи хранится там только в зашифрованном виде (хэш). Читать и менять данные можно только через проверку кода и личного ключа участника.
**Как удалить:** «Выйти» удаляет ваши данные из облака. «Удалить» удаляет всю семью целиком. «Новый код» сразу отключает старый.

Без интернета всё работает как обычно. Изменения отправятся сами, когда появится связь.

## Как выложить на свой хостинг

Код синхронизируется с GitHub (в Lovable: Project Settings → GitHub). Сайт собирается командой `npm run build`.

Семейный доступ использует серверные функции, поэтому для него нужен хостинг, на котором они работают (Lovable или Cloudflare Workers). На хостинге только для статических сайтов личный бюджет работает полностью, а семейный экран показывает, что облако недоступно.
